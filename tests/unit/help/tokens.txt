Usage: wildburrow tokens [OPTIONS] [COMMAND] [ARGS]...

  List the tokens the saved login's server has and those minted here; or mint one with `tokens
  new`.

Options:
  -h, --help  Show this message and exit.

Commands:
  deny  Stop tokens logging in, by the ID `tokens` lists or by name, ending their sessions...
  new   Mint a token signed with your SSH key, for a server that trusts the key in...
  sync  Register the tokens minted here with --offline with the saved login's server, so any...
