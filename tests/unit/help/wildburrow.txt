Usage: wildburrow [OPTIONS] [COMMAND] [ARGS]...

  Expose local ports on your own domain. Alone in a terminal, asks what to do.

Options:
  --version   Show the version and exit.
  --no-input  never ask anything, failing instead; also WILDBURROW_NO_INPUT=1
  -h, --help  Show this message and exit.

Commands:
  connect    Tunnel a local port (the default command): wildburrow 3000 myapp '*.foo'
  login      Save the server and how to connect to it.
  logout     Forget the saved server.
  names      List the names bound on the server right now, and which are yours.
  tunnels    List who is connected to the server, as far as you may see.
  kick       End sessions on the server, each TARGET a session id from `wildburrow tunnels`,...
  links      List who may get into your locked tunnels, and who has; add or end their links...
  tokens     List the tokens minted on this machine, which a server can't list; or mint one...
  users      List the server's users, or invite and manage them; for an admin.
  join       Join SERVER with the CODE an admin invited you with.
  config     List every client setting, its value and where it comes from; or change what's...
  serve      Run the server.
  service    Run the server as a system service: systemd on Linux, launchd on macOS.
  passwords  Passwords for the server's password auth plugin.
