usage: wildburrow [-h] [--version] {connect,login,serve,hash-password,token} ...

Expose local ports on your own domain.

positional arguments:
  {connect,login,serve,hash-password,token}
    connect             tunnel a local port (default command)
    login               save the server and how to connect to it
    serve               run the server (configured through WILDBURROW_* variables)
    hash-password       print an argon2 hash for the password auth plugin
    token               create a token for the token auth plugin

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
