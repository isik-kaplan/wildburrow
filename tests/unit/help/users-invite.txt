Usage: wildburrow users invite [OPTIONS] NAME

  Invite NAME to the server.

  Prints a one-time code they set up their own password or key with, by `wildburrow join`.

Options:
  --server TEXT                 server to use instead of the saved one
  --token TEXT                  token to log in with; means --auth token
  --ssh-port INTEGER            SSH port (1-65535) (default: 2222)
  --user TEXT                   SSH user (default: your local user)
  --transport [ssh|websocket]   how to reach the server (default: ssh)
  --auth [key|password|token]   how to log in (default: key)
  --identity TEXT               SSH key for websocket
  --url TEXT                    websocket base URL override
  --reconnect / --no-reconnect  reconnect when the connection drops (default: on)
  --retry-delay SECONDS         first wait before reconnecting, doubled after each failure
                                (default: 1)
  --retry-max SECONDS           longest wait between reconnects (default: 30)
  --expires DURATION            how long the invite can wait to be used (default: 7d)
  -h, --help                    Show this message and exit.
